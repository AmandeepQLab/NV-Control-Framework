Message:
  Add per-pixel noise statistics to ODMR scans

  ODMR scans now keep every OFF/ON repeat per pixel, rather than only the
  ROI mean. From these, each scan reports fast (repeat-to-repeat) and slow
  (average-to-average) noise and a combined uncertainty. This shows
  whether more repeats or more averages would actually help.

  Changes:
  - ODMR experiment and worker record per-pixel repeat pairs into a
    statistics cube, saved as odmr_statistics.h5 next to the scan data
  - New statistics module computes final mean, fast/slow SD and SEM,
    and combined uncertainty
  - ODMR window shows a statistics summary with a "How are these
    calculated?" explanation; the control panel now scrolls
  - HDF5 saving chunks one 2-D image per chunk for cubes with more than
    one leading dimension

  Tested: pytest <result>

Message:
  Improve ODMR fitting: manual starting values and two-dip global fit

  Lorentzian fits could converge on the wrong dip when the automatic
  starting guess was poor. You can now supply starting values, and a new
  bounded two-Lorentzian fit is available for full spectra.

  Changes:
  - "Supply Initial Fit Parameters" dialog in the ODMR window:
    resonance location(s) required; contrast and FWHM optional
  - Single and double Lorentzian fits accept those starting values,
    and reject resonance locations outside the measured range
  - New bounded two-Lorentzian global fit with uncertainties

  Tested: pytest <result>
